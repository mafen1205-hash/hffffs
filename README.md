# Конвертер валют (расширение для Chrome / Edge / Brave)

## Установка
1. Распакуйте папку `currency-converter`.
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`).
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку `currency-converter`.
5. Закрепите иконку расширения на панели и пользуйтесь.

## Возможности
- Конвертация между ~160 валютами
- Кнопка быстрой смены направления ⇄
- Курсы кэшируются на 6 часов, работает офлайн по сохранённым данным
- Запоминает последнюю пару валют и сумму
- Тёмная тема подстраивается под систему

Источник курсов: open.er-api.com (бесплатно, без ключа).
